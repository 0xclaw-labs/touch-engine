- 日期：2026-10-14（模板创建；所有实测行初始 NOT_VERIFIED）
- 票：HUI-1663 实体NFC与门店部署验收
- 本文档性质：**现场实测记录模板**。工程准备（受控链路机验）已在本仓完成（见 `not-verified.md` 的「已机验」段）；本矩阵的每一行都必须由真机/实物实测后填写，未测行保持 NOT_VERIFIED，**不得凭型号参数推断填写**。

## 填写说明

1. **一行一次实测**：每个「机型×系统×入口方式×标签形态」组合单独一行。多行同型号合并视为造假。
2. **状态值只允许三种**：`NOT_VERIFIED`（未测）/ `PASS` / `FAIL`。FAIL 行必须附失败描述与恢复动作结果。
3. **每行必填**：操作人、日期、被测系统/浏览器版本、标签实物型号。缺任一项该行无效，回退 NOT_VERIFIED。
4. **耗时**：从「碰卡动作开始」到「活动页首屏可见」，秒表/录屏帧计数均可，记录到整秒。
5. **版本快照**：每次实测记录当天活动内容版本（管理面触点详情的 stage/更新时间）与 `PUBLIC_BASE_URL` 域名，保证录屏可对账。
6. **录屏**：票面要求脱敏录屏。文件命名 `device-matrix/<日期>-<机型>-<入口>.mp4`，脱敏（遮挡顾客面部/门店敏感信息）后归档到本目录。
