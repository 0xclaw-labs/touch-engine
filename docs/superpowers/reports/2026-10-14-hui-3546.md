## 1. 交付面

### 领域包 `server/internal/participation/**`（G2 独占，参与表只由本包修改）
- `participation.go`：五态状态机（pending/in_progress/awaiting_review/fulfilled/canceled，无 success 布尔；fulfilled 仅 MarkFulfilled 可达）；attempt 四态（prepared/handed_off/completed/canceled，发布证据态归 1670/1671 域）。
- `credential.go`：交接令牌 = `ptx_` + 128-bit 随机体 + SHA-256 校验位；库内只存全 token 的 SHA-256；对外展示走 `redact.MaskCode`。
- `reserver.go`：`BenefitReserver` 受信端口（`Reserve(ctx, ParticipationRef) (ReserveResult, error)`），一参与一 `BenefitSlot`；生产接线随 HUI-1671（本票 nil=pending，绝不伪报已保留）。
- `service.go`：真实 SQLite 存储与全部行为——幂等开始（同键回原行、换访客同键=冲突）、visitor 绑定读取（租户边界取自行内，访客面无可伪造租户入参）、lookup 恢复未完参与、预览期换选、attempt 交接冻结（内容包+规则版本）、凭据铸造/兑换/撤销、PeekCredential（店员先鉴权后消费）、MarkFulfilled（幂等、拒降级、本票无路由）、Cleanup（过期凭据 24h 宽限删除；canceled 参与超保留窗匿名化）。

### 迁移 0020-0022（additive，SQLite）
- `0020_participations`（UNIQUE(tenant,campaign,idempotency_key) 承载幂等；benefit_reservation_state CHECK 只有 confirmed 才是确认）
- `0021_participation_attempts`（attempt 级冻结 content_pack_version + rule_version）
- `0022_handoff_credentials`（token_hash UNIQUE、purpose/target_scope、expires_at、used_at 防重放、revoked_at）

### HTTP 面（`FEATURE_PARTICIPATION` 默认 off；off=路由不注册 404 + handler 双保险统一 404）
- 顾客面（无会话概念；首方 cookie `touch_participation_visitor` 仅同浏览器续接）：`POST /api/v1/participations`（显式开始，幂等）、`POST .../lookup`、`GET/PATCH .../{id}`(+content/cancel/attempts)、`POST .../{id}/attempts`、`POST .../{id}/handoff`（冻结+铸造凭据+qr_payload）、`DELETE .../handoff/{credentialId}`、`POST /api/v1/participations/handoff/redeem`（仅 customer_resume）。
- 店员面（requireSession + authz.ActionReadRecord + 域层门店作用域，双 fail-closed）：`GET /api/v1/participations/{id}/staff-view`、`POST /api/v1/participations/staff/redeem`（Peek 定位→租户/门店鉴权→才消费凭据→awaiting_review）。
- 错误语义：未知 token/参与一律 404（防枚举）；过期 410；已用/已撤销 409；目标不符 403；终态 422。
- config.go / server.go 仅最小窄补丁（开关常量、字段、构造、集中一段路由注册），未重排他人代码。

### web 层
- BFF catch-all（`web/src/app/api/[...path]/route.ts`）天然透传新路由组，零改动。
- `web/src/lib/participation.ts`：视图类型 + `benefitCopy` 白名单（**只有 confirmed 才出现「已保留」**）+ canResume/canHandoff/credentialLooksLive/isSafeQrPayload；`web/tests/participation.test.ts` 源码级断言（仓内 node 无 DOM 惯例）。
