# HUI-2222 正式商家入口与受控登录 Implementation Plan

**Goal:** 登录商家从生态入口落到真实「今天」工作台；店员角色按 `FEATURE_SERVICE_DESK`
（默认 off）看到「确认与核销」入口；受控登录链（匿名/已登录/多组织/无权限/过期/切组织）
在本地 harness 全部正向验证；`/admin`、`/c/{code}` 零回归。

**Architecture:** 开关走 Go config（仓内 FEATURE_* 惯例），经 whoami `features.service_desk`
单缝下发 web；入口可见性判定收口 `web/src/lib/work/service-desk.ts` 纯函数；两个既有 tk-nav
槽位（WorkFrame + TodayDesk）条件渲染；E2E 用 web/e2e 自含 harness 增补受控登录链 spec。

**Tech Stack:** Go 标准库（`cd server && GOWORK=off go test ./...`、`go vet ./...`）；
Next.js 15（`npx vitest run`、`npm run build`）；Playwright（`bash web/e2e/run.sh` partial）。

**Spec:** `docs/superpowers/specs/2026-10-14-hui-2222-design.md`

## Global Constraints

- `/` 页面零改造（已 TodayDesk）；`/c/**`、`/work/rewards`、`materials`、`/work/service` 页面、
  中央 layout 样式、`web/src/lib/eco-nav/**` 全部禁碰。
- FEATURE_SERVICE_DESK 默认 off；off=入口不渲染、无任何新路由；on=仅入口渲染（404 归 3562）。
- Go 只打窄补丁：config 字段 + whoami features；不新增 HTTP 路由。
- 角色集 {org_owner, store_manager, staff} 对齐 authz ActionUpdate；agent 不可见。
- 每任务先红后绿、小提交；不保存 secret；E2E 端口 18460-18462 被 lsof 占用则跳过并注明。
