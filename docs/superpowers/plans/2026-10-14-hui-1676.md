## Step 2 campaignenable 叶子包（纯函数，红→绿）

- `server/internal/campaignenable/campaignenable.go`：
  - 类型：VerificationMode/BenefitKind/BudgetMode/DedupBasis/StaffVerifyScope/
    OutOfStockAction 常量；ChannelRef{Platform,EntryMode,Scenario}；Reward；Spec。
  - `ValidateSpec(Spec) error`：形状矩阵（枚举合法、copy 与 mode 成对约束留到
    Check、数量/预算非负、窗口 RFC3339 形状、渠道三元组非空、slot 形状）。
  - `Check(Spec, Facts) Decision{Allowed, Reason, Field}` 固定顺序：
    copy_missing → content_not_ready → content_blocked → content_grant_expired →
    channel_closed → channel_not_admitted → no_runnable_channel →
    benefit_ref_missing → benefit_version_mismatch → benefit_stock_missing →
    window_conflict → campaign_ended → store_mismatch。
  - `BuildDisclosure(Spec, ruleVersion int, now) Disclosure`：告知快照
    （rule_version/mode/customer_copy/dedup_statement/预算口径/窗口/generated_at）。
- 测试 `campaignenable_test.go`：矩阵全负例 + 正路径 + 固定顺序 + 快照字段。

## Step 3 store 层（红→绿）

- `server/internal/store/store_campaign_publish_config.go`：
  - `GetPublishConfig(tenantID, campaignID)`（跨租户 ErrNotFound）。
  - `UpsertPublishConfigDraft(tenantID, campaignID, spec, changedBy)`：
    校验 ValidateSpec；同事务 version+1 + 全量快照 revision（create/update）；
    enabled 状态下保存 → 自动回 draft（enable 时点快照保留）。
  - `EnablePublishConfig(tenantID, campaignID, version int, disclosure string, changedBy)`：
    条件 UPDATE（status IN draft,paused → enabled），钉 enabled_version + disclosure +
    revision 'enable'；0 行 → 读回现行（幂等 200 语义交 handler）。
  - `PausePublishConfig`（enabled→paused，revision 'pause'）。
  - `ListPublishConfigRevisions`（oldest-first）。
- 测试：版本递增、五动作留痕、跨租户 404、enabled 保存草稿化、并发启用
  （goroutine ×2 各 20 次 → 单一 enabled 版本、修订数 ≤ 2）、同版本证明
  （enable 后 GetCampaignRulesByCampaign 与 GetCampaignRules 同 version）。

## Step 4 httpapi 接线（红→绿）

- `server/internal/httpapi/handlers_campaign_config.go`，全部走 rulesGate +
  `campaignScoped(..., authz.ActionManageCampaignRules, ...)`：
  - `GET/PUT /api/v1/campaigns/{id}/publish-config`（PUT DisallowUnknownFields +
    ValidateSpec；422 拒时带 machine reason）。
  - `POST /api/v1/campaigns/{id}/publish-config/enable`：组装 facts
    （contentpack.Distributable+ListAdoptions；ListChannelAdmissions×Gate(RewardPlay=true)；
    ListRewardInventory 按 slot+rule_version+available；campaign 窗口；ListStores）
    → campaignenable.Check → 拒 422 {error=reason, field} → 过则 EnablePublishConfig。
  - `POST /api/v1/campaigns/{id}/publish-config/pause`。
  - `GET /api/v1/campaigns/{id}/publish-config/snapshot`：G3 契约
    {campaign_id,version,allowed_evidence,slots}（rewardops.Snapshot 同形）+
    disclosure；draft/paused → 409 not_enabled（诚实状态，不当已承诺）。
- server.go 条件注册（FEATURE_CAMPAIGN_RULES 块内）。
- 测试 `server_campaign_config_test.go`：off 基线 404、authz 仅 owner、
  跨租户 404、CRUD 形状矩阵、enable 全负例原因码（空内容/未准入渠道/
  无库存/版本不齐/时间冲突/错店/copy 缺失）、暂停后老参与读路径仍通、
  快照契约形状。
