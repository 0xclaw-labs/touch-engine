## 1. 事实面（读码结论）

- `server/internal/assetlib`（HUI-1666，Done 不重做）：素材引用行 = 平台 upload 产物引用
  （asset_ref）+ sha256 版本锚点；source/purpose/grant_ref 引用级声明必填；回流候选 =
  `candidate` 标记（先入候选不直接替换）；选择台账只追加、版本冻结。
- `web/src/app/work/materials/page.tsx`（126 行）：现状确实是"列引用 + 手填 asset_id/version"，
  不满足门店使用 —— 本票整页升级。
- httpapi 两面纪律：`/api/v1/...` 管理面（session+membership）；`/api/v1/public/...` 顾客面
  （无 session、GET-only、白名单字段）。登记制 FEATURE 开关（默认 off）双保险写法：
  路由不注册 + handler gate 统一 404。
- 迁移按文件名序 apply、按名记录，缺号安全 → 本票用预留号段 0028/0029/0030（additive only）。
- 授权：`authz.ActionManage*` 仅 org_owner；业务动作用 ActionCreate/ActionReadList/ActionUpdate。
- web 测试惯例：`web/tests/*.test.ts` 源码级断言（node 环境无 DOM），`npx vitest run`。

## 2. 关键设计问题与裁决（root 代答）

### Q1 领域包放哪、与 assetlib 什么关系？
**裁决**：新建叶子包 `server/internal/contentpack`，纯规则无 IO（与 assetlib 同风格：枚举、
校验矩阵、机器原因码、ValidationError）。内容包**引用素材版本而不是复制文件**：版本行冻结
`(asset_id, asset_ref, sha256)` 三元组快照，最大化复用 HUI-1666 基线。

### Q2 表结构与迁移编号？
**裁决**（additive SQLite，只许 0028/0029/0030）：
- **0028** `content_packs`：id、tenant_id、campaign_id、store_id（可空）、title、created_by、
  created_at、updated_at。活动归属 + 商家 + 标题。租户内 (campaign_id, title) 唯一。
- **0029** `content_pack_versions`（**不可变版本**）+ `content_pack_version_events`（只追加处理记录）：
  - 版本行：content_kind（video|imagetext）、video/cover 素材引用快照
    （asset_id/asset_ref/sha256 各三列，imagetext 用 JSON 图文引用数组）、
    title/body/topics（话题 JSON 数组）、门店/价格/有效期事实字段
    （store_name/price_note/valid_note，提交时必填）、平台适配版本列表
    （platform_versions JSON：每项 platform + note + source_version_id，同一来源可追溯）、
    授权引用快照（grant_refs JSON + grant_until 可空 RFC3339）、必要标识要求
    （marking JSON：ad_required/incentive_disclosed/ai_generated）、
    status（draft|candidate|adopted|retired|blocked）、blocked_reason、
    source（merchant_upload|asset_lib|product_photo_return）、
    **idempotency_key（制作工程/回流去重键，结构预留，租户内唯一，NULL 可重复）**、
    version_no（包内自增序号）、created_by、created_at。
    **内容列零 UPDATE：旧版本不可被回流覆盖，只能新开版本。**
  - 事件表：version_id、kind（created|submitted|adopted|superseded|blocked|returned）、
    note、actor、created_at，只追加 = 「处理记录」。
- **0030** `content_pack_adoptions`：活动×平台的**当前采用指针**：(campaign_id, platform) 唯一，
  version_id + adopted_by + created_at；换版 = 显式 adopt 覆盖指针（历史在事件表）。

### Q3 商家流程与三入口怎么落地？
**裁决**：`/work/materials` 页升级为三入口工作台；活动详情页以**最小窄补丁**挂
`<ContentPackPanel>`（新组件，不重写 HUI-2628 在改的布局，只在 `page.tsx` 增一个 section +
import，冲突点在报告声明）：
1. **上传已有内容**：表单收标题、内容形式（视频/图文）、封面/素材**从素材库挑选**
   （选择器显示封面/用途/媒体类型/时长格式/来源/授权声明/适用平台，不出现 asset_id/version
   技术字段）、标题/正文/话题、门店/价格/有效期、标识要求勾选 → 落为包版本草稿。
   v1 无物理文件仓（1666 纪律），"上传"= 声明式登记引用；素材不在库时引导先去素材库登记。
2. **从素材库选择**：同一选择器，选库内已有素材为视频/封面/图文，直接进候选/草稿。
3. **帮我制作**：按钮**只在存在真实 handoff 能力时启用**。本票不接真实引擎
   （产品图/GoBoost/AiCut/数字人真实交接归 HUI-1745 与后续联调），故：
   - `GET /api/v1/content-handoffs/capabilities`（管理面）如实回答
     `production_available:false + reason`；
   - `POST /api/v1/campaigns/{id}/content-handoffs` 收活动目的/门店资料/选定素材/期望形式 +
     idempotency_key，**落库去重**（同一交接重试不新建制作工程——结构上幂等键已落库），
     但如实回答 503 `handoff_unavailable`；UI 显示禁用按钮 + 商家语言原因，不阻塞前两个入口。
- **候选 → 预览/编辑文案 → 明确采用**：编辑文案 = 新开版本（旧版零改动）；采用 = 显式
  adopt 端点按平台写指针；采用后顾客侧读同一版本，不随机刷新换片。

### Q4 顾客侧快照读怎么开？
**裁决**：`GET /api/v1/public/links/{code}/content-snapshot?platform=...`——
**顾客可触达的快照读端点走 FEATURE_CONTENT_PACKS，默认 off**（仓内红线：管理面不加开关、
公共面登记制开关双保险）。按链接解析活动 → 取该活动当前采用版本（按平台，缺省默认平台）→
返回**不可变快照**（pack_version_id + 冻结内容），只含公开字段（标题/正文/话题/门店/价格/
有效期/封面引用/标识要求/平台适配），**不含**内部素材簿记、候选行、blocked 细节、授权原文。
消费方：HUI-1670 / HUI-1896。blocked/撤权版本 = 该端点答 not_distributable（阻止新分发）。

### Q5 媒体交接怎么准备？
**裁决**：`contentpack` 包内实现受控下载 URL 服务函数（**非永久公有化素材库**）：
- Mint：HMAC 签名 token（密钥 = InternalToken + 域分隔符派生），绑定
  (version_id, asset_id, sha256, content_type, disposition, 过期时刻)；有效期默认 10 分钟、
  上限 1 小时。
- 兑换：`POST /api/v1/content-pack-versions/{id}/media-handoff`（管理面，1670 服务端消费）
  铸造 → `GET /api/v1/media-handoffs/{token}` 兑换，校验权限、有效期、租户归属，返回
  平台 upload 引用元数据（asset_ref/sha256/content_type/Content-Disposition），供发布器
  按官方要求拉取；**文件字节零过本服务、零进 Context/Notify**。素材缺失（平台侧查无）=
  明确 media_missing。

### Q6 回流与采用安全语义？
**裁决**：
- **回流**：`POST .../content-packs/{packId}/return-candidates`（HUI-1745 产品图成果未来接线点，
  本票以已有合法素材自测跑通）带 idempotency_key：同键重放返回既有候选（幂等，不新建）；
  **一律落为候选新版本，绝不覆盖当前采用版**；晚到旧稿同样只进候选。
- **撤权/重大内容问题**：`POST .../versions/{id}/block`（原因必填，落事件）→ 版本
  status=blocked → 不可被 adopt、快照答 not_distributable（阻止新分发）；已参与顾客保留
  原版本内容（版本不可变）+ 事件表处理记录。授权过期：版本携带 grant_until，adopt 与
  快照分发路径检查过期 → grant_expired 拒绝。
- **同一交接重试不新建制作工程**：handoff 幂等键唯一约束 + 重放语义。
- **访客多次碰触不新增生成费用**：快照端点 GET-only、零生成通道（结构保证）。

### Q7 是否重建 CMS？
**裁决**：不。最小增量只组织「可采用版本」三张表 + 事件表；文案复用既有字段结构
（复用 1666 素材/模板/文案表的组织方式，不复制其存储）。

## 3. 端点清单（管理面不加 FEATURE 开关；公共面走 FEATURE_CONTENT_PACKS 默认 off）

管理面（session + authz；pack 管理动作 ActionManageContentPacks 仅 org_owner；查询走
ActionReadList/ActionReadRecord）：
- `POST /api/v1/campaigns/{id}/content-packs` 建包
- `GET /api/v1/campaigns/{id}/content-packs` 列包（含版本与采用态）
- `POST /api/v1/content-packs/{packId}/versions` 新版本（草稿或候选；回流走专用端点）
- `GET /api/v1/content-packs/{packId}` 包详情（含版本列表）
- `POST /api/v1/content-packs/{packId}/versions/{versionId}/adopt` 明确采用（platform 必填）
- `POST /api/v1/content-packs/{packId}/versions/{versionId}/block` 阻止新分发（原因必填）
- `POST /api/v1/campaigns/{id}/content-packs/{packId}/return-candidates` 回流候选（幂等键）
- `POST /api/v1/campaigns/{id}/content-handoffs` 制作交接 brief（幂等键；未接引擎 503）
- `GET /api/v1/content-handoffs/capabilities` 制作能力如实申报
- `POST /api/v1/content-pack-versions/{versionId}/media-handoff` 铸造受控媒体交接 URL
- `GET /api/v1/media-handoffs/{token}` 兑换（管理面，供 1670 服务端消费）

公共面（FEATURE_CONTENT_PACKS 默认 off；off = 路由不注册 + gate 统一 404）：
- `GET /api/v1/public/links/{code}/content-snapshot?platform=...` 不可变快照（公开字段白名单）

## 4. 测试矩阵（票面验收映射）

| 场景 | 落点 |
| --- | --- |
| 跨租户引用拒绝 | store/httpapi：pack/version/adopt/snapshot 全路径租户过滤，跨租户=NotFound |
| 授权过期 | 版本 grant_until 过期 → adopt 422 grant_expired；快照 not_distributable |
| 媒体缺失 | 素材引用在 lib_assets 查无 → 建版本 422 media_missing |
| 重复回流 | 同幂等键重放 → 返回同一候选行，零新增 |
| 晚到旧稿 | 采用后到达的回流旧稿 → 只落候选，采用指针不变 |
| 商家改价 | 改价 = 新版本；已采用版本内容与指针零变化 |
| 源素材更新 | 库内同 ref 新 sha 新行；版本冻结旧 (asset_id, sha256) 快照不漂移 |
| 弱网重登恢复 | web 测试：会话重建后重拉 packs/adoptions，不把失败当成功 |
| 采用版不静默变化 | 快照两次读取逐字段一致；候选/block 不动指针 |
| 390/430 与桌面 | 响应式样式类 + 窄面板布局源码级断言 |
| 幂等交接 | 同幂等键 handoff 重放 = 同一 brief 行，不新建工程 |

## 5. 边界与不做

- 不接真实制作引擎/不部署生产/不花真实钱（诚实降级显示原因）。
- 不动：活动配置规则面（1676）、`/c/[code]` 公共页（1896）、发布适配（1670）、奖励域
  （1671）、work 共享 layout；活动详情页只加最小窄补丁。
- 真实生态产品往返（产品图回流）自测以已有合法素材模拟走 return-candidates 契约；
  真实往返联调归 1745 —— 如实申报 NOT_VERIFIED。
- 大文件零进 Context/Notify；本票无任何生成/模型调用通道。
