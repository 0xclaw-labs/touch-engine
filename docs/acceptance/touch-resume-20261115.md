## 本轮修复及验证依据

### 运营入口能正常确认会话，并隔离旧账号意图

原 `OpsGate` 把选组织、无组织和服务错误都当成“未登录”；六个视图又各自读取会话，导致首次请求携带空组织。现在复用原 `MerchantGate` 和同一个会话上下文，支持同页登录、按名称选组织、真实空态和错误重试。平台权限仍来自受信 ops grant，组织负责人不会自动成为平台运营。

授权结果绑定会话快照；同组织换号也重新核对，迟到成功/拒绝不能恢复旧业务。Terra 进一步复现“结束支持访问”的旧 GET 在换号后继续 POST：主负责人先在原链加存活及身份代次检查，原失败用例转绿，再修复从全平台列表误选他人或过期授权的问题。现在关闭前读取原商户详情，由服务端确认当前主体在该商户仍有效的支持授权。

页面关闭请求携带 `own_access_only=true`，后端再次核对执行时的受信主体。两人都持管理权的真实 HTTP 测试证明：新账号不能执行原账号的“结束自己的支持访问”意图，拒绝后原授权不变；原账号可正常关闭。已有显式平台管理关闭他人授权仍保持，并经 Terra 独立 HTTP 用例验证。网络结果不明不报成功；原按钮重试成功后清掉旧错误并显示确认结果。

证据：[运营实施报告](touch-resume-20261115/ops-session-review.md)、[Terra 独立对抗复审及修复复验](touch-resume-20261115/ops-adversarial-review.md)。最终组件回归 24 项通过，包含无权/有权换号、换目标、授权迟到、503 恢复、本人有效授权和错误反馈消除。

### 付款不因开通失败消失，未知事实不伪装成零

原统计只按 `active` 订单累计支出，漏掉已付款但仍在开通或开通失败的订单；硬件退款还可能混入订阅退款。现按受信 `payment_paid` 事实计同一订单一次，以原发生时间落窗；订阅、硬件付款与退款分别保留，退款不冲销原付款。缺金额、缺币种和混币不输出完整金额。

Terra 发现无法解析退款时间会被 SQL 过滤，随后显示已知零。主负责人沿原写入路径复现，并同时修复付款最早日期被 `MIN` 忽略坏时间后猜出的同类问题：任何无法归窗的该类事实，都使金额合计保持未知；已经确定落窗的单数/笔数与无法归窗数分列，页面明确提示核对。其他租户和订单类型不受污染，真正没有退款的已读本地账仍保留零。

窗口继续遵循公开的 **UTC 整秒粒度、边界含** 合同；`23:59:59.900Z` 属于最后一秒桶，下一整秒才在窗外。Terra 原纳秒排除预期经核对撤回，没有为了让错误测试通过而修改业务口径。空 `payment_ref` 及同 `refund_ref` 不同事件的处理，按现有合同裁定，不偷偷在统计层新增必填或去重规则。

证据：[统计实施](touch-resume-20261115/analytics-review.md)、[Terra 复审与原红复验](touch-resume-20261115/analytics-adversarial-review.md)、[权威付款与退款合同裁定](touch-resume-20261115/payment-contract-review.md)。真实 HTTP、原事件逐行复算与页面共享手工预期；新边界覆盖坏时间与正常记录混合、租户/类型隔离、时区偏移和末秒。Web 统计定向 3 文件、62 项通过。

### 收银可用性必须能消费原订单

原实现仅凭两个应用标识就返回支付可用，普通 SSO 跳转并不携带受控原单消费上下文。主负责人复现了未登记目标和已登记普通应用均被误报可用的情况。当前明确返回 `checkout_unwired`，正常页面不承诺支付接续，也不因此重新下单；报价、原订单回查、付款主体、幂等、权限和权威事实入口保留。

这项修复纠正能力误报，**没有完成原单支付消费端**。HUI-4664 仍需真实受控 checkout 引用、订单/付款组织/冻结价格绑定、幂等结果回查和原任务返回。仅登记应用、通用充值、GoBoost 商品结算或拼接订单参数不能代替该合同。

剩余不只是正式环境：公共侧还需提供消费 Touch 原单的 producer 合同与实现，Touch 侧仍需 adapter、checkout 引用映射、同单恢复和受控返回上下文。这些是可开发的工作，应按公共权威合同实施，不能笼统写成“等待外部”，也不能把拟契约当成已有上游端点。现有真实微信商品 checkout 和原单收款组件可复用，但没有直接接通本业务。

证据：[收银就绪复审](touch-resume-20261115/billing-readiness-review.md)、[原单 checkout 可实施性核查与剩余开发范围](touch-resume-20261115/checkout-implementation-feasibility.md)。账单 Go 定向及 Web 2 文件、12 项回归通过；正式支付、退款、发票与实卡仍未验。
